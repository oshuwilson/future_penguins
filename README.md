# **Code Repository for Paper: Projecting the Future Distributions of Penguins Under Different Climate Scenarios**

This repository contains all code used to produce species distribution models projecting the future distributions of seven Southern Ocean penguin species under both a low-emissions climate scenario (**SSP1-2.6**) and a high-emissions climate scenario (**SSP5-8.5**).

---

# **Key Folders**

## **1. Track Processing**

Code used to clean, standardise, and state-space model raw tracking data, and to collate processed data into a single database.

## **2. Topographic Constraints**

Code used to extract topographic variables (e.g., distance to coast and elevation) for each known colony and to delimit potential breeding areas under future climate scenarios.

## **3. Climatic Model**

Code for the terrestrial species distribution model used to assess how climate change may impact breeding habitat suitability across the Southern Ocean.

## **4. At Sea Model**

Code for the oceanographic species distribution model used to project climate-driven changes in foraging habitat suitability across the Southern Ocean.

---

# **Additional Folders**

## **Climate Data Processing**

Climate Data Operators (CDO) bash functions used to process CMIP6 climate data.

## **R**

Custom R functions developed and used throughout the modelling framework.

## **Figures**

Scripts used to create the main figures presented in the manuscript.

## **Supplementary Figures**

Scripts used to create supplementary figures accompanying the manuscript.
